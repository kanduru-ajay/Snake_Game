🐍 Snake Game Using Python

📌 Project Description

The Snake Game is a simple interactive game developed using Python and the Pygame library.

In this game, the player controls a snake using the keyboard arrow keys. The snake moves around the screen, eats food, and grows longer each time it eats.

The objective is to collect as much food as possible without colliding with the walls or the snake's own body.

The game ends when the snake hits a wall or collides with itself.

🎮 Game Controls
Key	Action
↑ Up Arrow	Move Up
↓ Down Arrow	Move Down
← Left Arrow	Move Left
→ Right Arrow	Move Right
📋 Game Rules
Control the snake using the arrow keys.
Eat the red food to increase your score.
Every time the snake eats food, it grows longer.
Avoid hitting the screen boundaries.
Avoid colliding with your own body.
The game ends when the snake collides with a wall or itself.
